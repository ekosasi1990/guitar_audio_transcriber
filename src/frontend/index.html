Rhythm

Automatic timing snaps attacks to the BPM grid, keeping pauses and different rhythms. Consistent groups of four repeated attacks can fit four beats in a bar; disable repeated groups if that interpretation is wrong. Set BPM before transcription to control that grid; changing BPM afterwards changes playback speed.

Assign an intended rhythm manually

Use quarter-beat steps (0.25, 0.5, 1…). A chord uses one attack slot. Blank means even spacing.
